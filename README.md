# Common Sense AI design demo

This repository hosts a static review copy of the Common Sense AI V2 redesign in English and Dutch. It publishes from the root of the `main` branch via GitHub Pages at <https://algorhythm-be.github.io/csai-demo/>.

The live Common Sense AI site is maintained separately. This review copy uses direct email links for contact and does not run the live form backend or analytics.
