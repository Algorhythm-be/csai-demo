# Common Sense AI homepage design demo

The [GitHub Pages demo](https://algorhythm-be.github.io/csai-demo/) implements the Figma frame [Common Sense AI / Homepage redesign / Desktop](https://www.figma.com/design/sTyi5yB9dlexeDKrBU4hXN/Common-Sense-AI?node-id=113-114) as one responsive homepage.

The logo, client logos, portrait, and linework come from that frame. The scratch animation uses its staggered path timing. Homepage navigation jumps to sections; individual services, cases, jobs, contact, and Dutch link to the live website.

To preview locally, serve this folder with any static HTTP server. GitHub Pages publishes from the root of `main`.
